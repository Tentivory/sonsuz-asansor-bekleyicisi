# sonsuz-asansor-bekleyicisi

## Dünyanın En Yavaş, En Anlamsız ve En Komik Asansör Simülatörü

Bu repo, modern şehir hayatının en büyük sorununu çözmek için yaratıldı: **Asansör beklerken geçen o sonsuz zaman.**

### Nasıl Çalışır?

1. `python asansor.py` çalıştırın.
2. Asansör rastgele katlarda durur.
3. Hiçbir yere varmaz.
4. Siz çıkana kadar (veya çıkamayana kadar) devam eder.

### Özellikler (Abartılı)

- **Gerçekçi bekleme süreleri**: 2-5 saniye arası, tıpkı gerçek hayatta olduğu gibi.
- **Gizli kat**: Sadece özel kişiler için. (Kim olduklarını bilmiyoruz.)
- **Kısılma modu**: %10 ihtimalle asansör kısılır. Teknik ekip 3 iş günü içinde gelir. Belki.
- **Bürokrasi dostu**: Her şey yavaş, her şey prosedüre uygun.

### Kurulum

```bash
git clone https://github.com/Tentivory/sonsuz-asansor-bekleyicisi.git
cd sonsuz-asansor-bekleyicisi
python asansor.py
```

Python 3 yeterli. Bağımlılık yok, çünkü asansör de bağımlılık sevmez.

### Uyarılar

- Bu script sonsuz döngüdedir. Gerçekten.
- Bilgisayarınız ısınabilir. (Hayır, ısınmaz, sadece zaman kaybedersiniz.)
- Çıkmak için Ctrl+C kullanın. Veya bilgisayarı kapatın.

### Katkıda Bulunma

Pull request'ler kabul edilir, ama yavaş incelenir. Tıpkı asansör gibi.
